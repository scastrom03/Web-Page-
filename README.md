# Samuel Castro Martínez

Página personal en español con experiencia profesional, formación académica y certificaciones.

## Publicación
En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta / (root).

## Certificaciones
El enlace «Configurar certificaciones» permite cargar imágenes y URLs. Los cambios se guardan solo en ese navegador. Descarga la página personalizada y reemplaza index.html en este repositorio para publicar los cambios. Mantén cv-samuel-castro.pdf junto al HTML.

Los distintivos iniciales son marcadores visuales y no insignias oficiales. Las URLs de verificación están pendientes de añadir.
